========================================================================
  ربط النطاقات المخصصة — شبكة comm.ly
  ملف تعليمات +صناديق جاهزة للرفع
========================================================================

طريقة الصندوق:
  اسم الدومين مكتوب خارج الصندوق، والـ DNS المطلوب إدخاله داخل [ ... ].
  مثال:   3.com.ly   [ comly-n3.pages.dev ]

------------------------------------------------------------------------
  ١) النطاقات الستة التي تستخدم أسماء خوادم كلاودفلير
------------------------------------------------------------------------

  3.com.ly    [ comly-n3.pages.dev ]     →  dns/3.com.ly.txt
  4.com.ly    [ comly-n4.pages.dev ]     →  dns/4.com.ly.txt
  6.com.ly    [ comly-n6.pages.dev ]     →  dns/6.com.ly.txt
  7.com.ly    [ comly-n7.pages.dev ]     →  dns/7.com.ly.txt
  8.com.ly    [ comly-n8.pages.dev ]     →  dns/8.com.ly.txt
  9.com.ly    [ comly-n9.pages.dev ]     →  dns/9.com.ly.txt

  خطوات الرفع لكل نطاق على حدة:
    1. افتح dash.cloudflare.com واختر النطاق (مثلاً 3.com.ly).
    2. من القائمة: DNS  ←  Records  ←  Import and Export.
    3. تحت "Import DNS records" اختر الملف الموافق له من مجلد dns.
    4. أبقِ "Proxy imported DNS records" مُفعّلاً (السحابة البرتقالية
       مطلوبة حتى يعمل ربط Cloudflare Pages).
    5. اضغط Import وانتظر دقيقة أو دقيقتين.

  إدخال يدوي بديل (لو فضّلتَ عدم الرفع):
    Type   : CNAME
    Name   : 3.com.ly
    Target : comly-n3.pages.dev
    Proxy  : ON  ☁️
    (كرّر مع بقية النطاقات بنفس النمط)

------------------------------------------------------------------------
  ٢) النطاق الرئيسي comm.ly — حالة خاصة
------------------------------------------------------------------------

  comm.ly   [ comm-ly.pages.dev ]

  أسماء خوادمه الحالية عند Afternic:
    ns1.afternic.com  /  ns2.afternic.com
  أي أنه ليس ضمن حسابك في كلاودفلير، لذلك ملف الاستيراد أعلاه لا ينطبق عليه.

  خياران:
    أ) عند Afternic: أضف CNAME للاسم comm.ly (أو @) بقيمة
       comm-ly.pages.dev إن كان مزوّد DNS يسمح بـ CNAME على جذر النطاق.
    ب) الأفضل: غيّر nameservers لـ comm.ly إلى:
         ian.ns.cloudflare.com
         nancy.ns.cloudflare.com
       ثم أضف النطاق إلى حساب كلاودفلير، وبعدها ارفع الملف:
         dns/comm.ly.txt

------------------------------------------------------------------------
  ٣) التحقق بعد الإدخال
------------------------------------------------------------------------

  بعد الرفع أخبرني «تم»، وسأفعل التالي خلال جلسة OAuth جديدة (30 دقيقة):
    - أتحقق من تحوّل حالة النطاقات من pending إلى active.
    - أتحقق من سجلات CNAME عبر DNS العام.
    - أعيد اختبار المواقع على النطاقات المخصصة نفسها.
    - أحدّث ملف التسليم وأدفع التغييرات.
